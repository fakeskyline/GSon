# GSon Web

Веб-версия локального конвертера GSon. Открой `index.html` через локальный HTTP-сервер или размести папку на статическом хостинге.

## Возможности
- GeoJSON ↔ KML / KMZ / GeoPackage
- KML внутри KMZ (приоритет doc.kml)
- WGS 84 / EPSG:4326 проверка перед экспортом в KML/KMZ/GeoJSON
- WKB геометрии в GeoPackage
- Много слоёв GeoPackage при чтении
- Тёмный интерфейс Material 3 Expressive, адаптивный для телефона
- Шрифты Ulm Grotesk из исходного проекта, загружаются локально из fonts-data/

## Запуск
Открой папку через HTTP, например:
```bash
python -m http.server 8080
```
Затем открой http://localhost:8080

Из-за ограничений браузеров открытие через `file://` может блокировать загрузку локальных шрифтов и Service Worker. На GitHub Pages / любом статическом хостинге всё работает.

## GeoPackage
Для чтения и записи GPKG приложение использует sql.js 1.13.0 и WebAssembly с CDN Cloudflare. Содержимое файлов не загружается в облако: SQL.js работает локально в браузере. Для первого использования GeoPackage требуется интернет, чтобы получить SQLite WebAssembly. После загрузки браузер может сохранить библиотеку в HTTP-кэше.

## Ограничения
- Перепроецирование координат не выполняется. GeoJSON/KML/KMZ экспорт требует EPSG:4326 / WGS 84.
- KML читает Placemark и основные геометрии Point, LineString, Polygon и MultiGeometry.
- GeoPackage — векторные таблицы; растровые тайлы и нестандартные расширения не конвертируются.
- KMZ при чтении выбирает doc.kml, если он присутствует, иначе первый KML в архиве.
