# GSon Web

Самостоятельная веб-версия локального конвертера GSon.

## Запуск
Откройте папку через локальный HTTP-сервер:
```bash
python -m http.server 8080
```
Перейдите на http://localhost:8080

Открытие через `file://` может блокировать локальные шрифты и Service Worker.

## Форматы
- GeoJSON: чтение и запись FeatureCollection, Feature и одиночных Geometry.
- KML: чтение Placemark, Point, LineString, Polygon, MultiGeometry; запись основных геометрий и ExtendedData.
- KMZ: чтение doc.kml (или первого KML в архиве) и запись ZIP с doc.kml.
- GeoPackage: чтение/запись векторных таблиц SQLite через sql.js и GeoPackageBinary/WKB.

## Локальность и SQLite
Файлы и геоданные не отправляются на сервер. Для чтения и записи GPKG при первом использовании загружается библиотека sql.js и WebAssembly с Cloudflare CDN (интернет нужен только для получения движка). Остальные форматы и интерфейс работают локально. Браузер может сохранить загруженную библиотеку в своём HTTP-кэше.

## Шрифты
Ulm Grotesk ExtraBold и Medium встроены в `fonts-data/` в виде gzip/base64-частей и восстанавливаются локально браузером.

## Ограничения
- Перепроецирование не выполняется. Экспорт в GeoJSON/KML/KMZ и текущая запись GPKG рассчитаны на EPSG:4326 / WGS 84.
- KML поддерживает Placemark и основные векторные геометрии; стили, NetworkLink, GroundOverlay и временные расширения не конвертируются.
- GPKG поддерживает векторные таблицы; растровые тайлы и нестандартные расширения не конвертируются.
- Атрибуты KML ExtendedData при чтении представлены строками.
