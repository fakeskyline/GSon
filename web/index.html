GSon Web

Локальный конвертер векторных геоданных. Файлы читаются и преобразуются на устройстве, не отправляясь на сервер.

Для работы с GeoPackage используется SQLite WebAssembly. При первом обращении к GPKG библиотека загружается с CDN.
