# GSon

GSon — веб-приложение для локальной конвертации векторных геоданных. Android-приложение удалено: репозиторий содержит только веб-версию.

## Запуск
Откройте папку проекта через локальный HTTP-сервер, например:
```bash
python -m http.server 8080
```
Затем перейдите на http://127.0.0.1:8080.

## Форматы
GeoJSON, GeoPackage (GPKG), KML и KMZ. Обработка файлов выполняется в браузере. Для GPKG SQLite WebAssembly загружается с CDN при первом использовании, поэтому для этой операции требуется интернет. Перепроецирование CRS не реализовано; экспорт GeoJSON/KML/KMZ требует EPSG:4326.

## Шрифт
Один исходный файл Nunito: `fonts/nunito.ttf`. Он используется и для заголовков, и для обычного текста. Никаких Base64-частей или datafonts нет.
