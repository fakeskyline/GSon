# GSon

Локальный веб-конвертер GeoJSON, GeoPackage, KML и KMZ.

## Запуск
`python -m http.server 8080` → http://127.0.0.1:8080

## Производительность
- Разбор и сериализация GeoJSON выполняются в отдельном Web Worker, чтобы не блокировать интерфейс и анимации.
- GeoPackage использует SQLite WebAssembly (sql.js). Сейчас runtime загружается с CDN при первом использовании GPKG; для полностью автономного режима нужно положить sql.js и sql-wasm.wasm локально.
- Для обычных GeoJSON/KML/KMZ нет отдельного C++/WASM-ядра: добавлять его без профилирования означало бы усложнить сборку, но не гарантировать ускорение. Главный поток освобождён для интерфейса на операциях GeoJSON.

Ограничения: перепроецирование CRS не реализовано; экспорт KML/KMZ и GPKG требует EPSG:4326. Поддержка KML — распространённые Placemark-геометрии, не весь стандарт.
