# GSon

GSon — веб-конвертер векторных геоданных. Репозиторий содержит только веб-версию; Android-проект и Android CI удалены.

## Запуск локально
```bash
python -m http.server 8080
```
Открой http://127.0.0.1:8080.

## Форматы
GeoJSON, GeoPackage (GPKG), KML и KMZ. Файлы обрабатываются в браузере. Для GPKG SQLite WebAssembly загружается с CDN при первом использовании, поэтому требуется интернет. Перепроецирование CRS не реализовано; экспорт GeoJSON/KML/KMZ требует EPSG:4326.

## Шрифт
Весь интерфейс использует один Nunito. Положи оригинальный файл в `fonts/nunito.ttf`. Файл шрифта не кодируется в Base64 и не разбивается на части. Если папка пуста, скачай приложенный архив `fonts-nunito.zip` и распакуй его в корень репозитория.
